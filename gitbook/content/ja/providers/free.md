# 無料プロバイダー - コストゼロのフォールバック

無料のレーンは最後の一手です。サブスクリプションを使い切り、格安のレーンも上限に達したとき、これらのプロバイダーはなお答えます — あなたにコストをかけずに。

そのうち3つは、すぐ接続できる形で同梱されています: iFlow、Qwen、Kiro。3つとも無料で作れるアカウントを使い、3つともプロバイダーが定めた独自の制限を持ち、それはVelaが定めるものではありません。

---

## 概要

- 🆓 **iFlow** — 広いモデルメニューを持つ無料アカウント: Qwen3、Kimi K2、DeepSeek、GLMなど
- 🆓 **Qwen** — Qwen自身のプラットフォームで、Qwen自身のモデルを
- 🆓 **Kiro** — AWS Builder IDかソーシャルのログインを通してClaudeファミリーを

**考え方:** コンボの最後にそのうちのひとつを置いてください。そうすれば「何もかもクォータ切れ」は緊急事態ではなくなり、少し遅い午後になるだけです。

> **「無料」には正直に。** 無料枠にはレート制限があり、ときどき使えず、予告なく変わります。割り当てはプロバイダーが公表しています。あなたのアカウントに実際に何が残っているかは、Velaが**Quota**ページに示します。「月18万リクエスト」のような見出しにすぎないものは、動きうる上流の数字です。

---

## iFlow

### 得られるもの

ひとつのログイン、ひとつのメニュー。このリリースが同梱するプロバイダー:

| モデル | 向いていること |
|-------|----------|
| `if/qwen3-coder-plus` | コード生成 |
| `if/qwen3-max` | 最も強いQwen3の汎用モデル |
| `if/qwen3-235b-a22b-thinking-2507` | 推論の重い作業 |
| `if/kimi-k2` | 長いコンテキストのコーディング |
| `if/deepseek-r1` | 一歩ずつの推論 |
| `if/deepseek-v3.2` | 高速な一般的な会話 |
| `if/glm-4.7` | 格安レーンと同じモデルを、コストなしで |
| `if/qwen3-vl-plus` | 視覚 |

### セットアップ

**ステップ1: 接続する**

```
Dashboard → Providers → iFlow → Connect
```

**ステップ2: ログインする**

ブラウザがiFlowのサインインページを開きます。アカウントがなければ作り、接続を承認してください。それ以降、Velaがトークンを新しく保ちます。

iFlowのアカウントには、OAuthではなくセッションクッキーで認証するものもあります。ダッシュボードがクッキーの欄を出すなら、求められる値を貼り付けてください。

**ステップ3: 使う**

```
Model: if/qwen3-coder-plus
```

### 最初の無料の選択肢になる理由

多様性。ひとつのアカウントで複数のベンダーのモデルに届きます。どの無料プロバイダーを試すか考えたくないとき、良いデフォルトになります。

## Qwen

### 得られるもの

Qwen自身のモデルを、Qwenが供します:

| モデル | 向いていること |
|-------|----------|
| `qwen/qwen-max` | 最も強い汎用モデル |
| `qwen/qwen-plus` | バランス |
| `qwen/qwen-turbo` | 速く、軽い作業 |
| `qwen/qwen-long` | 非常に長い文書 |

### セットアップ

```
Dashboard → Providers → Qwen → Connect or Add API key
```

あなたのアカウントによって、ログインか、Qwenのコンソールのキーになります。そのあとモデルを`qwen/qwen-plus`のように使います。

### いつ手を伸ばすか

- iFlowがレート制限されていて、いま何かが要るとき。
- 長い文書の作業で、`qwen/qwen-long`が優位なとき。
- 無料だけのコンボの、2番目の段として。

---

## Kiro(コストなしのClaude)

### 得られるもの

AWSのコーディング環境であるKiroを通して、Claudeファミリーを:

| モデル | 向いていること |
|-------|----------|
| `kr/claude-sonnet-5` | 日常のバランス |
| `kr/claude-sonnet-4.5` | 実績ある安定の選択 |
| `kr/claude-opus-4.8`、`kr/claude-opus-5` | 難しい問題 |
| `kr/claude-haiku-4.5` | 手早い作業 |

それぞれに`-thinking`と`-agentic`の変種(`kr/claude-sonnet-4.5-thinking`など)もあり、推論を見たいときに使えます。

### セットアップ

**ステップ1: 接続する**

```
Dashboard → Providers → Kiro → Connect
```

**ステップ2: ログインを選ぶ**

AWS Builder IDがふつうの選択肢です。GoogleとGitHubのログインも、プロバイダーから提供されています。

**ステップ3: 使う**

```
Model: kr/claude-sonnet-4.5
```

### 品質の選択肢である理由

それは、お金を払っているのと同じモデルファミリーを、何も払わずに使えるということです。だからこそ`kr/...`は、コンボのなかでも「無料なのに、まだ良い」自然な枠になるのです — 試験ではなく、本物の仕事に使う枠。

---

## 並べて見る

| プロバイダー | 接頭辞 | 同梱のモデル数 | ログイン | 最も得意なこと |
|----------|--------|-----------------|-------|---------|
| **iFlow** | `if/` | 15 | OAuthまたはクッキー | 多様性 |
| **Qwen** | `qwen/` | 4 | ログインまたはキー | 長い文書 |
| **Kiro** | `kr/` | 44 | AWS Builder ID / ソーシャル | Claudeの品質 |

---

## ツールで使う

### 無料モデルをひとつ、直接

```
Base URL: http://localhost:32060/v1
API Key:  [your Vela key]
Model:    kr/claude-sonnet-4.5
```

### 無料だけのコンボ

```
Dashboard → Combos → Create
  Name:   zero-cost
  Models: 1. kr/claude-sonnet-4.5      ← quality first
          2. if/qwen3-coder-plus        ← variety
          3. qwen/qwen-plus             ← last resort
```

コスト: いつでも、何もなし。速度と可用性: 今日の無料枠が許すぶんだけ。

### 3つのレーンをすべて使うコンボ

```
Dashboard → Combos → Create
  Name:   never-stuck
  Models: 1. cc/claude-opus-5          ← subscription
          2. cx/gpt-5.6-sol            ← second subscription
          3. glm/glm-4.7               ← cheap
          4. minimax/MiniMax-M2.1      ← cheaper
          5. kr/claude-sonnet-4.5      ← free, still good
          6. if/qwen3-coder-plus       ← free, variety
```

これは、設計全体が指し示している鎖です: 払ったものを使い、安いものに落ち、何もないところで終わらない。

**落ちていく仕組み:** コンボは、リクエストが*失敗*したときに次のモデルへ移ります — クォータのエラー、レート制限、タイムアウト、拒否されたプロンプト、未知のモデル。日次の割り当てが少なくなってきたからといって、先回りして切り替えることはしません。かたい上限が欲しいなら、APIキーに設定してください(**Endpoint & Key → budget**)。そうすればVelaは、黙って使うのではなく、429で断ります。

## 無料枠から最大限を引き出す

### 1. 最後に置き、そして本気でそうする

無料のモデルを先頭にすると、あなたの仕事をすべて吸い上げ、有料のクォータは使われないまま期限切れになります。最後に置けば、何もかからず、その日を救います。

### 2. 仕事にモデルを合わせる

```
Reasoning / tricky code : if/qwen3-235b-a22b-thinking-2507, kr/claude-opus-4.8
Everyday coding         : kr/claude-sonnet-4.5, if/qwen3-coder-plus
Fast and cheap          : qwen/qwen-turbo, if/deepseek-v3.2
Long documents          : qwen/qwen-long
Vision                  : if/qwen3-vl-plus
```

### 3. それだけの上に本番を建てない

無料のレーンは予告なく変わります: モデルが消え、制限が締まり、プロバイダーに悪い午後が訪れます。鎖の床として使ってください。床の全体設計としてではなく。

### 4. クォータではなく、優先度を見る

無料枠は、はっきり断るのではなく、優先度で絞ることがよくあります: あなたのリクエストは支払っている顧客の後ろで待ちます。返事が遅く感じるなら、たいてい理由はそれで、ほかの無料プロバイダーに切り替えるのが直し方です。

## トラブルシューティング

### 「OAuth failed」

- オンラインで、プロバイダーのサイトがふつうのブラウザで開くか確かめてください。
- 別のブラウザか、拡張機能を切ったプライベートウィンドウを試してください。
- **Providers**から切断し、再接続してください。

### 「Model not available」

- **Providers**でプロバイダーが接続済みと出ているか確かめてください。
- モデルIDがゲートウェイの一覧と寸分違わないか確かめてください: `curl http://localhost:32060/v1/models -H "Authorization: Bearer <key>"`。

### 「Slow responses」

無料のレーンは最も優先度が低い。ほかの無料プロバイダーを試すか、静かな時間帯に働くか、コンボを先へ進めさせてください。

### 「昨日は動いていて、今日は止まった」

それは無料枠の性質です。再接続する、同じプロバイダーの別のモデルを試す、あるいは戻ってくるまで別の無料プロバイダーに寄りかかってください。
