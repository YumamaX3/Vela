# Velaへようこそ

**Claude、Codex、Geminiをひとつのエンドポイントから使う — そして、サブスクリプションのクォータが尽きたら、格安や無料のバックアップでコーディングを続ける。**

Velaは、あなたのコーディングツールとAIプロバイダーのあいだに立つ、小さなゲートウェイです。すべてのツールをひとつのアドレスに向けておけば、Velaがあとを受けて、リクエストごとにどのプロバイダーが答えるかを決めます — まずはすでに対価を払ったサブスクリプション、次に格安のもの、そして最後に無料のもの。

Claude Codeの月末クォータが使われないまま消えていくのを眺めたことがあるなら、あるいはリファクタリングの途中でレート制限に一時間を奪われたことがあるなら、Velaはその午後のために作られています。

---

## Velaとは、平たく言えば?

あなたのコーディングツール(Cursor、Cline、Continue、Claude Code、Codex、そのほか数十あります)は、どれも「OpenAI互換」の言葉を話します。ベースURLとキーを渡せば、その先で答えるものと話し始めます。

Velaは、その先で答えます。背後には、あなたが接続したプロバイダーが控えています — Claude Codeのログイン、Codexのログイン、GLMのキー、無料のKiroアカウント — そしてVelaは、リクエストごとに、答えるべき相手へと流します。

**これが解くもの:**
- ❌ サブスクリプションのクォータが毎月、使われないまま期限切れになる
- ❌ レート制限に、文の途中で止められる
- ❌ いくつもの有料API、それぞれに毎月の請求書
- ❌ ツールとプロバイダーのあいだを手で切り替える

**かわりに手に入るもの:**
- ✅ **サブスクリプションを最後の一トークンまで使い切る** — Claude Code、Codex、Copilotなど、リアルタイムで追跡
- ✅ **格安のバックアップ** — GLM-4.7が100万トークンあたり$0.60 / $2.20、MiniMax M2.1が$0.30 / $1.20
- ✅ **無料のフォールバック** — iFlow、Qwen、Kiro。いずれもコストはゼロ
- ✅ **自動フォールバック** — ひとつが尽きたら、気づかないうちに次が引き継ぐ

## 主な機能

### 🔄 3つの階層、ひとつのエンドポイント

順番を一度決めたら、あとはコーディングを続けるだけです:

```
Tier 1 (SUBSCRIPTION): Claude Code → Codex → Copilot
  ↓ quota exhausted
Tier 2 (CHEAP):        GLM-4.7 → MiniMax M2.1 → Kimi
  ↓ spend cap reached
Tier 3 (FREE):         iFlow → Qwen → Kiro

→ The next one answers. You keep typing.
```

第2階層と第3階層は、あなたが組み立てないかぎり自動では働きません。その鎖に名前をつけるのが**コンボ**です。[コンボのガイド](features/combos.md)が、数クリックで組み立てる手順を案内します。

### 📊 クォータ追跡

- プロバイダーごとのトークン消費量を、ライブで
- リセットまでのカウントダウン(毎時・毎日・毎週・毎月)
- 有料レーンのコスト見積もり
- 必要ならAPIキーごとの予算上限で、かたい歯止めを

### 🎯 あらゆるOpenAI互換ツールで動く

✅ **Cursor** • **Cline** • **Claude Code** • **Codex CLI** • **Roo** • **Continue** • **ベースURLを受け取るそのほかすべて**

### 💰 現実的なひと月

月に1億トークンを使う開発者、その大半はすでに持っているクォータを通して:

```
60M via Gemini CLI        : $0   (free allowance, upstream figure)
30M via Claude Code       : $0   (subscription you already pay for)
 8M via GLM-4.7            : about $4.80
 2M via MiniMax M2.1       : about $0.40
```

[格安プロバイダーのページ](providers/cheap.md)が、これらの数字を一行ずつ辿ります。

## Velaはいくつのプロバイダーに対応していますか?

正直な答えは3つの数字です。それらは3つの別のものを測っているからです。3つとも2026-10-28、バージョン1.2.4で測ったもので、いつでも自分で導き直せます:

| 数 | 意味 | 自分で確かめる方法 |
|-|-|-|
| **189** | レジストリにあるプロバイダーファイルの数 — 誰かが書いたものすべて | `ls open-sse/providers/registry/*.js \| grep -v index.js \| wc -l` |
| **186** | アプリが実際に見ているエントリ数(3つのファイルは意図的に読み込まれていない) | `node -e "import('./open-sse/providers/registry/index.js').then(m=>console.log(m.default.length))"` |
| **145** | リクエストが実際に届けるトランスポートの数 | `node -e "import('./open-sse/providers/index.js').then(m=>console.log(Object.keys(m.PROVIDERS).length))"` |

つまり: **ダイヤルできるプロバイダーは145**、アプリが見ている186のうちの、書き留められた189のうちの。

この差はそれ自体で説明がつきます。3つのファイル(`devin-cli`、`trae`、`windsurf`)はディスク上にありますが、生成されたインデックスからコメントアウトされています — ふたつはツール呼び出しの十分な対応を欠き、ひとつはシェルへのアクセスを持つローカルエージェントを起動するからです — だから誰からも見えません。186のうち残りの41は、トランスポートを宣言していないエントリです: メディア、ツール、あるいは作業中のもの。チャットのリクエストを送るものからは何にも届きません。読み込まれていようといまいと、どのファイルもレジストリを読む誰かにとっては意味があって、そのどれもマーケティングの数字ではありません。上の3つのコマンドをあなたのクローンで走らせれば、来月の数字ではなく今日の数字が返ってきます。

認証の仕方で分けると、186はAPIキーのプロバイダー131、OAuthログイン23、無料枠のレーン22、Webクッキーのプロバイダー7、アカウントをまったく要さないもの3に分かれます。覚えておく必要はありません — ダッシュボードの**Providers**の部屋が一覧にしてくれます。

## なぜVelaが選ばれるのか

### すでに払っているものから、値段ぶんの価値を

すでにClaude CodeやCodexを使っていますか? Velaはそのクォータがどれだけ残っているかを追い、複数のアカウントのあいだを切り替え、リセットまでのカウントダウンを保ちます。目的はかんたんです: 買ったものを、期限が切れる前に使い切ること。

### 良いものが尽きたら、安く

| プロバイダー | 100万トークンあたり | リセットの目安 |
|----------|---------------|---------------|
| **GLM-4.7** | 入力$0.60 / 出力$2.20 | 毎日 |
| **MiniMax M2.1** | 入力$0.30 / 出力$1.20 | ローリングウィンドウ |
| **Kimi** | サブスクリプションプラン | 毎月 |

これらはVela自身がコスト見積もりに使う料率です(`open-sse/providers/pricing.js`)。最終的な裁きは、プロバイダーの請求書です。

### ほかがすべて尽きたら、無料で

- **iFlow** — 無料アカウント、多数のモデル(Qwen3、Kimi K2、GLM 4.7、DeepSeekなど)
- **Qwen** — Qwen自身のアカウントで、Qwenのモデルを
- **Kiro** — AWS Builder IDを通して、Claudeのモデルを

無料レーンにはレート制限があり、しかも予告なく変わります。最初の一手ではなく、最後の一手です。

## クイックスタート

Node.js 20以降が入っていれば、2分で終わります:

```bash
# The launcher installs itself and starts the gateway
npm install -g vela
vela
```

ダッシュボードは**http://localhost:32060/dashboard**にひとりでに開きます。デフォルトのパスワードはありません — ローカルのブラウザはそのまま入り、**設定 → アクセス**でパスワードを決めるまで、遠隔からのログインは閉ざされたままです。

そして、お好きなコーディングツールで:

```
Endpoint: http://localhost:32060/v1
API Key:  [create one under Dashboard → Endpoint & Key → Create Key]
Model:    cc/claude-opus-5        (or any model, or a combo name)
```

[→ 詳しいはじめかたのガイド](getting-started/quick-start.md)

## どんなふうに使われているか

### 個人の開発者に
すべてのツールをひとつのエンドポイントで動かし、サブスクリプションを先に使い、そして「念のため」のAPIクレジットに払うのをやめる。

### 小さなチームに
小さなサーバーでVelaを一度動かし、人ごとにひとつのAPIキーを、それぞれの支出上限を添えて配り、利用状況をひとつの場所で見る。

### 複数のマシンからコーディングする人に
VPSやコンテナにVelaを配備し、ノートPCからも、タブレットからも、電話からも届ける。[クラウドのガイド](deployment/cloud.md)がそれを扱います。必要になるリバースプロキシの話も含めて。
